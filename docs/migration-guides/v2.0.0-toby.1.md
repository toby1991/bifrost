# Toby fork upgrade to Bifrost v2

## Frozen baseline

- Whole-tree base: `core/v1.8.4^{}` (`6d60595b574e5a89289e1449825d0854aa99eabb`).
- Included official modules: Core `v1.8.4`, Framework `v1.6.0`, HTTP Transport `v2.0.0`.
- Existing fork tags are immutable: `core/v1.7.4-toby.7` and
  `framework/v1.5.4-toby.1` must not move.
- `helm-chart-v2.0.1` is a Helm chart release, not Bifrost HTTP `v2.0.1`.
- Do not create a `transports/v2.0.0-toby.*` module tag. The upstream v2 tag
  keeps the v1 module path (`github.com/maximhq/bifrost/transports`), so a v2
  module version cannot be consumed by normal Go module resolution.

## Capability preservation plan

- [ ] Port and adapt provider lifecycle shutdown hardening.
- [ ] Port and adapt configurable stale-connection retry layers, including
  private-network dialer and streaming-client behavior.
- [ ] Port and adapt the dynamic-provider initialization switch.
- [ ] Port Gate video generation, retrieval, download, deletion and listing.
- [ ] Preserve Gate as a named-capable base provider and retain direct URLs in
  retrieval responses.
- [ ] Add the v2 Provider surface required by Gate with explicit unsupported
  behavior where Gate has no operation.
- [ ] Port the pure Framework chat-pricing API without catalog or Store lookup.
- [ ] Adapt pricing to the nested `BifrostCost` result and the v1.6 pricing
  fields, including ultrafast token prices and per-request cost.

## Verification plan

- [ ] Run targeted unit tests for lifecycle, retry layers, dynamic provider
  initialization, network config serialization and Gate operations.
- [ ] Run Core package tests without loading live provider credentials.
- [ ] Run Framework datasheet targeted and full package tests.
- [ ] Compile all Core and Framework packages with Go 1.27.
- [ ] Compile TokenEx against the local upgraded Core and Framework modules and
  run the LLMGW provider, pricing, asset-route and execution suites.
- [ ] Review the final range diff against both fork tags and record any
  intentional upstream-semantic changes.

## Release outputs

- Integration branch: `codex/bifrost-v2.0.0-toby.1`.
- Core tag: `core/v1.8.4-toby.1` after all Core capabilities pass.
- Framework tag: `framework/v1.6.0-toby.1` after the pricing API passes.
- Tags remain local until an explicit push request.
